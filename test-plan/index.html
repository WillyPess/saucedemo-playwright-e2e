08 / Bug Registry

Defects found during test automation
BUG-001

Product name displays as an internal test placeholder instead of a real product name

Severity: Low Status: Open
Linked: TC-INV-001 Found in: standard_user, Chrome, /inventory.html

Screenshot

Steps to reproduce

  1. Log in with standard_user
  2. Land on the inventory page
  3. Scroll down through the product list

Expected

All products display a real, descriptive, customer-facing name consistent with the rest of the catalog.

Actual

One product displays as "Test.allTheThings() T-Shirt (Red)" — a name that reads like an internal test string rather than a shipped product name.

BUG-002

error_user cannot remove items from the inventory page

Severity: Medium Status: Open
Linked: TC-USR-003 Found in: error_user, Chrome, /inventory.html

Screenshot

Steps to reproduce

  1. Log in with error_user
  2. Add a product to the cart from the inventory page
  3. Attempt to click "Remove" on that same product from the inventory page

Expected

Clicking "Remove" on the inventory page removes the item from the cart, same as it does for standard_user.

Actual

The "Remove" button on the inventory page does not remove the item when logged in as error_user. The item can only be removed by navigating to the cart page and removing it from there.
